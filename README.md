# Вариант 11 — виртуальная UNIX-оболочка

Учебная CLI-оболочка на Python с виртуальной файловой системой (VFS), авторизацией, сохранением состояния и управлением владельцами.

## Запуск

Нужен Python 3.10 или новее. В Windows выполните `run.bat`, в Linux/macOS — `sh run.sh`.

Первый запуск создаёт `data/vfs.json`, `data/users.json` и резервный снимок `data/initial_vfs.json`. Начальные учётные записи:

| Пользователь | Пароль |
| --- | --- |
| `student` | `student` |
| `root` | `root` |

Пароли учебные и хранятся открытым текстом в JSON. Не используйте эти файлы для настоящей системы учётных записей.

## Команды

- `help` — показать доступные команды.
- `ls [путь]` — показать содержимое каталога или имя файла.
- `cd [путь]` — перейти в каталог; без аргумента перейти в домашний каталог.
- `pwd` — вывести текущий виртуальный путь.
- `whoami` — вывести вошедшего пользователя.
- `useradd USER PASSWORD` — создать пользователя и его домашний каталог (только `root`).
- `chown USER PATH` — сменить владельца (только `root`).
- `vfs-init` — восстановить исходную VFS из `data/initial_vfs.json`.
- `exit` — завершить оболочку.

Пути абсолютные и относительные; обрабатываются `.` и `..`. VFS отделена от настоящей файловой системы компьютера. Данные автоматически сохраняются в JSON после команд.
